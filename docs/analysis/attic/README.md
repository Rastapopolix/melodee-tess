# Attic

Old working copies kept for reference, not built. `tessera.c.preflourish` and `tessera.h.preflourish`: an
abandoned, richer Tessera save format (189 bytes a track instead of 45) that also stored each FORM section's
recorded LOCK phrase and which sections were visited. A reference for phase 1's generator state
(`docs/analysis/housekeeping.md`).
